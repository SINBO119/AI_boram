## 요금제 추천 페이지

### 목적
서비스 진입 후 추천 방식을 선택한다.
직접 탐색과 자동 추천으로 흐름이 나뉜다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- 신규: 추천 방식 선택 — 플로우에서 확인되는 선택 항목은 직접 탐색과 자동 추천.
- 선택된 화면 시안이 없어 내부 배치와 사용 컴포넌트는 미정.

### 상태
- 기본: 추천 방식을 선택하는 단계.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 서비스 시작.
- 나가는 곳:
  - 직접 탐색 → 요금제 목록.
  - 자동 추천 → 사용 패턴 분석.

## 요금제 목록

### 목적
요금제 종류와 가격, 주요 혜택을 확인하고 탐색한다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- Header — Type=root. 제목은 “요금제 목록”.
  - Logo — 헤더 내부 로고.
- FilterChip
  - “전체”: State=selected.
  - “베이직”, “스탠다드”, “프리미엄”: State=default.
- 신규: 목록 안내
  - “나에게 맞는 요금제를 선택하세요”.
  - “요금제별 혜택을 확인한 후 구독할 수 있어요.”
- Card/Plan — State=default. 시안에 3개 배치.
  - 베이직: 월 5,900원 / 월 10회 이용 · 기본 기능 제공.
  - 스탠다드: 월 9,900원 / 월 30회 이용 · 기본 기능 + 이용 기록.
  - 프리미엄: 월 14,900원 / 무제한 이용 · 기본 기능 + 이용 기록.
  - Tag — 카드 내부 “추천” 표시.
  - Button — Type=Secondary, Size=sm, State=Default. 카드 내부 “요금제 보기”.
- 신규: 요금 안내 — “모든 요금은 부가세 포함 금액입니다.”

### 상태
- 기본: 전체 필터가 선택되어 있고 요금제 카드 3개가 표시됨.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳:
  - 요금제 추천 페이지에서 직접 탐색 선택.
  - 신청 완료 화면의 “요금제 더 보기”.
- 나가는 곳:
  - 플로우 기준 → 맞춤 요금제 추천 결과.
  - 시안의 “요금제 보기”와 플로우상 다음 단계의 구체적인 연결 조건은 미정.

## 사용 패턴 분석

### 목적
자동 추천 분기에서 사용 패턴을 분석한다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- 신규: 사용 패턴 분석 — 플로우에 존재하나 선택된 화면 시안 없음.
- 분석에 필요한 입력 항목, 분석 방식, 내부 사용 컴포넌트는 미정.

### 상태
- 기본: 자동 추천을 위한 사용 패턴 분석 단계.
- 로딩: 분석 진행 상태의 표현은 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 요금제 추천 페이지에서 자동 추천 선택.
- 나가는 곳: 맞춤 요금제 추천 결과.

## 맞춤 요금제 추천 결과

### 목적
직접 탐색 또는 사용 패턴 분석 이후의 요금제 추천 결과를 확인한다.
다른 요금제를 비교하는 흐름에서도 이 화면으로 돌아온다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- 신규: 맞춤 요금제 추천 결과 — 플로우에 존재하나 선택된 화면 시안 없음.
- 결과 항목과 사용 컴포넌트는 미정.
- 요금제 목록 화면과 동일한 화면인지는 확인되지 않아 별도로 유지.

### 상태
- 기본: 추천 결과를 확인하는 단계.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳:
  - 요금제 목록.
  - 사용 패턴 분석.
  - 요금제 상세에서 다른 요금제 비교 선택.
- 나가는 곳: 요금제 상세.

## 요금제 상세

### 목적
선택한 요금제의 가격, 제공 혜택, 구독 조건을 확인하고 신청 여부를 결정한다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- Header — Type=default. 제목은 “요금제 상세”.
  - icon/arrowLeft — 헤더 내부 뒤로가기 아이콘.
- Card/Price
  - 시안의 요금제: 스탠다드.
  - 월 9,900원.
  - “부가세 포함 · 매월 정기 구독”.
- 신규: 제공 혜택 제목 — “제공 혜택”.
- List/Row — Type=default. 제공 혜택 3개.
  - 이용 횟수: 월 30회.
  - 기본 기능: 제공.
  - 이용 기록: 확인 가능.
- 신규: 구독 안내
  - 이용 기간: 신청일부터 1개월.
  - 갱신 주기: 매월 자동 갱신.
  - 이용 횟수는 매월 새로 제공되며 남은 횟수는 다음 달로 이월되지 않음.
- Button — Type=Primary, Size=xl, State=Default. “구독 신청”.
- Button — Type=Secondary, Size=xl, State=Default. “뒤로”.
- 하단 동작은 시안에서 개별 Button으로 구성되어 있으며 BottomCTA 인스턴스는 사용되지 않음.

### 상태
- 기본: 선택한 요금제의 가격, 혜택, 구독 안내가 표시됨.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 맞춤 요금제 추천 결과.
- 나가는 곳:
  - 다른 요금제 비교 → 맞춤 요금제 추천 결과.
  - 이 요금제 선택 후 신청하기 → 로그인 여부 확인.
    - 로그인됨 → 구독 신청.
    - 비로그인 → 로그인/회원가입.
  - 시안의 “구독 신청”은 플로우의 신청하기 단계에 대응.
  - “뒤로” 및 헤더 뒤로가기의 구체적인 목적지는 미정.

## 로그인/회원가입

### 목적
비로그인 사용자가 구독 신청을 계속할 수 있도록 로그인 또는 회원가입을 진행한다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- 신규: 로그인/회원가입 — 플로우에 하나의 단계로 표기됨.
- 선택된 화면 시안이 없어 인증 방식, 입력 항목, 사용 컴포넌트는 미정.
- 로그인과 회원가입을 별도 화면으로 나누는지는 미정.

### 상태
- 기본: 비로그인 사용자의 인증 단계.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 요금제 상세에서 신청하기 선택 후 비로그인으로 확인된 경우.
- 나가는 곳: 로그인 또는 회원가입 완료 → 구독 신청.

## 구독 신청

### 목적
선택한 요금제와 신청 내용을 확인하고 신청 정보를 입력한다.
플로우의 “신청 폼 페이지”에 대응한다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- Header — Type=default. 제목은 “구독 신청”.
  - icon/arrowLeft — 헤더 내부 뒤로가기 아이콘.
- 신규: 신청 내용 제목 — “신청 내용”.
- List/Row — Type=default. 신청 요약 4개.
  - 요금제: 스탠다드.
  - 월 요금: 9,900원 (부가세 포함).
  - 제공 혜택: 월 30회 이용 / 기본 기능 + 이용 기록.
  - 이용 시작: 신청 완료 후 바로 이용.
- 신규: 신청자 정보 제목 및 입력 라벨
  - 제목: “신청자 정보”.
  - 시안의 입력 라벨: 이름, 이메일.
- Input — State=default. 시안에 이름과 이메일 입력란 2개 배치.
- 신규: 신청 안내
  - “신청 내용을 확인해 주세요.”
  - “구독은 신청일부터 매월 자동 갱신됩니다.”
- Button — Type=Primary, Size=xl, State=Default. “신청”.
- Button — Type=Secondary, Size=xl, State=Default. “취소”.
- 하단 동작은 시안에서 개별 Button으로 구성되어 있으며 BottomCTA 인스턴스는 사용되지 않음.
- 플로우에는 있으나 선택된 시안에 없는 구성:
  - 신규: 연락처·주소 입력 영역 — 플로우의 개인정보 입력 항목. 구체적인 필드 구성과 컴포넌트 연결은 미정.
  - 신규: 결제 정보 입력 영역 — 플로우에 카드 / 계좌 표기. 세부 입력 항목과 선택 방식은 미정.
  - 신규: 약관 동의 영역 — 플로우에 존재. 기존 “신규/약관 동의” 원본의 사용 여부는 미정이며 선택된 시안에는 배치되지 않음.
  - 신규: 입력 오류 안내 메시지 — 유효성 검사 오류 발생 시 표시. 문구와 표현 방식은 미정.

### 상태
- 기본: 선택 요금제의 요약과 신청자 정보 입력란이 표시됨.
- 로딩: 미정.
- 빈: 입력 전 상태의 구체적인 표현은 미정.
- 에러: 입력 정보 유효성 검사 실패 시 오류 안내 메시지를 표시하고 신청 폼으로 돌아가 수정.

### 이동
- 들어오는 곳:
  - 요금제 상세에서 신청하기 선택 후 로그인됨으로 확인된 경우.
  - 로그인/회원가입 완료.
  - 입력 유효성 검사 오류 후 수정.
- 나가는 곳:
  - 개인정보 입력 → 결제 정보 입력 → 약관 동의 → 입력 정보 유효성 검사.
  - 검증 완료 → 최종 확인 화면.
  - 검증 오류 → 같은 신청 폼에서 오류 안내 및 수정.
  - “취소” 및 헤더 뒤로가기의 목적지는 미정.
- 플로우 기준으로 신청 폼에서 바로 신청 완료로 이동하지 않음.

## 최종 확인 화면

### 목적
입력 정보 검증이 완료된 신청 내용을 최종 확인하고 신청을 확정한다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- 신규: 최종 확인 화면 — 플로우에 존재하나 선택된 화면 시안 없음.
- 신청 확정 동작이 존재함.
- 확인 항목, 동작의 표시 문구, 사용 컴포넌트는 미정.

### 상태
- 기본: 입력 정보 검증이 완료되어 신청을 최종 확인하는 단계.
- 로딩: 신청 정보 저장 중 표현은 미정.
- 빈: 미정.
- 에러: 저장 실패 시 처리와 표현은 미정.

### 이동
- 들어오는 곳: 구독 신청의 입력 정보 유효성 검사 완료.
- 나가는 곳: 신청 확정 → 신청 정보 저장 → 신청 완료.

## 신청 완료

### 목적
구독 신청 완료 사실과 신청 내역을 확인한다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- Header — Type=default. 제목은 “신청 완료”.
  - icon/arrowLeft — 헤더 내부 뒤로가기 아이콘.
- icon/doneMark — 완료 아이콘.
  - icon/check — 완료 아이콘 내부에 사용.
- 신규: 완료 메시지
  - 시안 제목: “구독 신청이 완료됐어요”.
  - 시안 설명: “개통 안내는 문자로 보내드려요”.
- 신규: 신청 내역 제목 — “신청 내역”.
- List/Row — Type=default. 신청 내역 5개.
  - 신청 번호.
  - 요금제.
  - 월 요금.
  - 신청 일시.
  - 신청자.
- BottomCTA — Layout=single.
  - Button — Type=Primary, Size=xl, State=Default.
  - 시안의 버튼 문구: “요금제 더 보기”.
- 시안 데이터 확인 필요:
  - 앞선 상세·신청 화면은 스탠다드 / 월 9,900원.
  - 완료 화면의 예시는 넉넉 무제한 / 월 85,000원으로 서로 다름.
  - 완료 화면에는 실제 저장된 신청 결과가 연결되어야 하며 예시 값 중 하나를 임의로 확정하지 않음.
  - 문자 안내 문구는 시안에 있으나 문자 발송 기능과 처리 단계는 플로우에 정의되지 않음.

### 상태
- 기본: 신청 정보 저장 후 완료 메시지와 신청 내역이 표시됨.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 최종 확인 화면에서 신청 확정 및 신청 정보 저장 완료.
- 나가는 곳:
  - 플로우 기준 → 마이페이지 / 구독 현황 확인.
  - 시안의 “요금제 더 보기” → 요금제 목록.
  - 마이페이지로 이동하는 UI는 선택된 시안에서 확인되지 않음.
  - 헤더 뒤로가기의 목적지는 미정.

## 마이페이지 / 구독 현황 확인

### 목적
신청 완료 이후 구독 현황을 확인한다.

### 라우트
미정 — 실제 경로가 자료에 명시되지 않음.

### 구성 요소
- 신규: 마이페이지 / 구독 현황 확인 — 플로우에 존재하나 선택된 화면 시안 없음.
- 표시할 구독 정보와 사용 컴포넌트는 미정.
- 구독 변경·해지 등 플로우에 없는 기능은 포함하지 않음.

### 상태
- 기본: 구독 현황을 확인하는 단계.
- 로딩: 미정.
- 빈: 미정.
- 에러: 미정.

### 이동
- 들어오는 곳: 신청 완료.
- 나가는 곳: 미정 — 플로우에 이후 이동이 정의되지 않음.
