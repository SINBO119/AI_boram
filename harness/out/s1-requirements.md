## 화면별 요구사항
| 화면 | 라우트 | 기능 ID | 규칙 | 열린 질문 |
|---|---|---|---|---|
| 요금제 추천 페이지 | /plans/recommend | — (PRD 6-1 분기 조건표: 완전 무제한 → B / 현재 기본 제공량 ≥ 최대 사용량 → C / 그 외 → A. PRD에 별도 기능 ID 없음) | R1, R2, R9, R10 | Q7, Q14 |
| 사용 패턴 분석 | /plans/recommend/analysis | F-A1, F-A2 | R1, R3, R4 | Q5, Q7, Q14 |
| 맞춤 요금제 추천 결과 | /plans/recommend/result | F-A1, F-A2, F-A3, F-A4, F-A5, F-A6, F-A7, F-A8, F-A9, F-B1, F-B2, F-B3, F-B4, F-C1, F-C2, F-D6 | R1, R2, R3, R4, R5, R6, R7, R8, R9, R10, R11 | Q2, Q3, Q4, Q5, Q6, Q8, Q9, Q14 |
| 요금제 목록 | /plans | F-L1, F-L2, F-L3, F-L4, F-C2 | R4, R11, R12 | Q1, Q8, Q14 |
| 요금제 상세 | /plans/[planId] | F-D1, F-D2, F-D3, F-D4, F-D5, F-D6, F-D7, F-L4 | R1, R2, R3, R4, R8, R11 | Q5, Q7, Q13, Q14 |

- 요금제 추천 페이지: 진입 시 고객 데이터(월별 데이터 사용량, 현재 요금제, 적용 중 할인, 이용 중 혜택)를 불러와 분기를 정한다 (PRD 6-1, 8장, DOMAIN 4-1).
- 화면 상태(로딩 / 빈 / 에러) 표현은 5개 화면 모두 미정 (Q14, PRD 8장).
- 여러 화면에 걸친 기능: F-A1·F-A2(분석 → 결과), F-C2(결과 → 목록), F-L4(목록 → 상세), F-D6(상세 → 추천 결과).

## 기능 ID 목록
| 기능 ID | 화면 | 요약 | 상태 (확정 / 가정 Q# / 미정 Q#) | 근거 |
|---|---|---|---|---|
| F-A1 | 사용 패턴 분석, 맞춤 요금제 추천 결과 | 기준 기간(최근 3개월)의 월별 사용량과 최대 사용량 표시 | 확정 | PRD 6-1 A, DOMAIN R1 |
| F-A2 | 사용 패턴 분석, 맞춤 요금제 추천 결과 | 이력이 3개월보다 짧으면 있는 만큼으로 계산하고 짧다고 알림 | 확정 | PRD 6-1 A, DOMAIN 4-6 |
| F-A3 | 맞춤 요금제 추천 결과 | 후보 = 데이터 충분(R2) + 할인 후 실납부액 ≤ 요금 상한(R3) | 확정 (5G / LTE 조건 포함 여부는 미정 Q9) | PRD 6-1 A, DOMAIN R2·R3 |
| F-A4 | 맞춤 요금제 추천 결과 | 최적 요금제 1개를 "추천"으로 표시 | 가정 (Q2): 후보 중 실납부액 최저 | PRD 6-1 A, DOMAIN R5 |
| F-A5 | 맞춤 요금제 추천 결과 | 대안: 한 단계 위 / 한 단계 아래, 최대 2개 | 가정 (Q3): 단계 = 기본 제공량 순 / 미정 (Q4): 대안에 상한 적용 여부 | PRD 6-1 A, DOMAIN R5 |
| F-A6 | 맞춤 요금제 추천 결과 | 한 단계 아래 대안은 기본 제공량 ≥ 평균 사용량일 때만, "가장 많이 쓴 달에는 모자랄 수 있음" 표시 | 확정 | PRD 6-1 A, DOMAIN R6 |
| F-A7 | 맞춤 요금제 추천 결과 | 후보가 없으면 데이터 충분한 요금제 중 실납부액 최저를 추천하고 "현재보다 20% 넘게 올라요" 안내 | 확정 | PRD 6-1 A, DOMAIN R7 |
| F-A8 | 맞춤 요금제 추천 결과 | 카드: 월정액, 할인 후 실납부액, 기본 제공량(QoS면 속도 제한 표시), 추가 혜택, 현재 대비 요금 차이 | 확정 (실납부액 계산 중 새 요금제에 적용되지 않는 할인 처리는 미정 Q5) | PRD 6-1 A, DOMAIN R4·R11 |
| F-A9 | 맞춤 요금제 추천 결과 | 사라지는 혜택이 있으면 카드에 경고 표시 | 확정 | PRD 6-1 A, DOMAIN R8 |
| F-B1 | 맞춤 요금제 추천 결과 | B 분기에서는 사용량을 근거로 쓰지 않음 | 확정 | PRD 6-1 B, DOMAIN R9 |
| F-B2 | 맞춤 요금제 추천 결과 | 원하는 혜택(제휴 구독 / 멤버십·할인)을 고객이 선택 | 미정 (Q6): 복수 선택 여부 | PRD 6-1 B |
| F-B3 | 맞춤 요금제 추천 결과 | 후보 = 지금 쓰는 요금제가 아닌 다른 완전 무제한 요금제 중 고른 혜택이 있고 실납부액 ≤ 요금 상한 | 확정 | PRD 6-1 B, DOMAIN R9·R3 |
| F-B4 | 맞춤 요금제 추천 결과 | 보여 줄 개수, 정렬, 후보가 없을 때의 처리 | 미정 (Q6) | PRD 6-1 B |
| F-C1 | 맞춤 요금제 추천 결과 | "지금 요금제가 적합해요"와 최대 사용량, 현재 기본 제공량 표시 | 확정 | PRD 6-1 C, DOMAIN R10 |
| F-C2 | 맞춤 요금제 추천 결과, 요금제 목록 | C 분기에서 목록으로 이동 가능 여부 | 미정 (Q8) | PRD 6-1 C |
| F-L1 | 요금제 목록 | 등급 필터 칩: 전체 / 베이직 / 스탠다드 / 프리미엄, 기본 선택 전체 | 확정 | PRD 6-2 |
| F-L2 | 요금제 목록 | 등급은 기본 제공량 구간으로 나눔 | 미정 (Q1): 구간 값 | PRD 6-2, DOMAIN R12 |
| F-L3 | 요금제 목록 | 카드: 이름, 월정액, 할인 후 실납부액, 기본 제공량, 추가 혜택 | 확정 | PRD 6-2, DOMAIN R11 |
| F-L4 | 요금제 목록, 요금제 상세 | 카드를 선택하면 요금제 상세로 이동 | 확정 | PRD 6-2 |
| F-D1 | 요금제 상세 | 선택 요금제와 현재 요금제 나란히 비교: 월정액, 할인 후 실납부액, 기본 제공량, 추가 혜택 | 확정 | PRD 6-3, DOMAIN R11 |
| F-D2 | 요금제 상세 | 최대 사용량 대비 데이터 충분 여부 표시 | 확정 | PRD 6-3, DOMAIN R1·R2 |
| F-D3 | 요금제 상세 | 실납부액 차이와 요금 상한(+20%) 초과 여부 표시 | 확정 | PRD 6-3, DOMAIN R3 |
| F-D4 | 요금제 상세 | 사라지는 혜택 경고 표시 | 확정 | PRD 6-3, DOMAIN R8 |
| F-D5 | 요금제 상세 | QoS 요금제는 기본 제공량과 그 뒤의 제한 속도를 함께 표시 | 확정 | PRD 6-3, DOMAIN R2 |
| F-D6 | 요금제 상세, 맞춤 요금제 추천 결과 | 다른 요금제를 비교하려면 추천으로 돌아감 | 확정 (목적지는 screens·flow 기준 추천 결과, screen-spec [5-10] 확인 필요) | PRD 6-3, screen-spec 5장 |
| F-D7 | 요금제 상세 | 신청 버튼은 범위 밖, 시안의 "구독 신청" 버튼 처리 | 미정 (Q13) | PRD 6-3, PRD 5장 |

## 어기면 안 되는 것
1. 화면에 고객 개인정보를 표시하지 않는다 (PRD 8장)
2. 요금은 월정액과 할인 후 실납부액을 함께 표시한다 (PRD R11)
